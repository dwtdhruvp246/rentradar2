# Implementation roadmap

## Phase 1: Foundation

Apply and verify the foundation migration, configure Auth redirects, seed countries and plans, complete profile onboarding, and test RLS with every role.

## Phase 2: Core property operations

Complete property, unit, tenant-link, lease, payment, maintenance, document, and receipt workflows. Add plan-limit checks and private Storage policies.

## Phase 3: Delegated management

Implement IPM/PMC relationships, selected-landlord context, staff assignment, permission templates, country-scoped admin staff, and management reporting.

## Phase 4: Professional operations

Add inspections, contractors, applications, leasing CRM, deposit settlement, task automation, admin notes, notifications, and localized pricing.

## Phase 5: Hardening

Run role-by-role RLS tests, Supabase advisors, accessibility checks, mobile viewport tests, performance checks, backup/restore drills, and launch readiness review.
